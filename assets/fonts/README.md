# Theme typefaces

These local files keep the gallery usable from disk and without a font CDN.

- Press Start 2P, by CodeMan38: https://github.com/google/fonts/tree/main/ofl/pressstart2p
- VT323, by Peter Hull: https://github.com/google/fonts/tree/main/ofl/vt323
- Caveat, by the Caveat Project authors: https://github.com/google/fonts/tree/main/ofl/caveat
- Anton, by Vernon Adams: https://github.com/google/fonts/tree/main/ofl/anton

Each family has its own adjacent SIL Open Font License file.

`../vice-wordmark.svg` is finished outline artwork set in Pricedown Black by
Ray Larabie / Typodermic Fonts, obtained from the designer's free desktop
collection. The desktop font is not embedded or distributed with the site.
Source and permitted finished artwork uses: https://typodermicfonts.com/downloads/
The palm-and-sunset illustration is original SVG artwork.
